# Data

Pilot/raw data collected for the muscle coactivation project (see [`../Poster`](../Poster)) — per-participant
anthropometrics (age, height, weight) and biceps brachii (BB) EMG baseline values across the six
coactivation conditions used in the study (0.5x, 1x, 2x, 4x, 8x, 16x self-selected level), along with the
timestamps of each condition within the recording session.

## De-identification

**Participant names have been replaced with codes (`Participant-01`, `Participant-02`, `Participant-03`)
before being added to this repo.** The original files identified participants by name; that's not
appropriate to keep in a public repository, so names were stripped at organization time. The
name-to-code mapping is not stored here — keep it in a private note if you need to recover it, and treat
that mapping itself as data that shouldn't be pushed to GitHub.

If more participant data files get added later, please de-identify them the same way (or ask and I'll do
it) before they go in this folder.
